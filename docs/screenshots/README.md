# Screenshots

Save final project screenshots in this folder using these filenames:

- `auth-page.png`
- `landing-page.png`
- `jobs-page.png`
- `seeker-dashboard.png`
- `employer-dashboard.png`
- `applicants-page.png`
- `admin-dashboard.png`
- `mobile-responsive.png`

Recommended capture checklist:

- Use real seeded/demo data where possible.
- Capture desktop screenshots at around `1440px`.
- Capture mobile screenshot at `390px` or `430px`.
- Avoid exposing real passwords, tokens, or private email accounts.
